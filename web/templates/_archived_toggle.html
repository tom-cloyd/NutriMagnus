{# Show/hide-archived toggle button for a list page (Recipes, Food Cache, Pantry). A link carrying an explicit show_archived=0|1, never a checkbox: an unticked checkbox submits nothing, so the route's _resolve_bool_pref() fell back to the remembered "show" pref and unticking changed nothing. Filled while archived items are showing, outline while they're hidden. `params` = the page's other query params to keep (q, sort, ...). #} {% macro archived_toggle(url, show_archived, noun, params={}) -%} {%- if show_archived %}Hide archived {{ noun }}{% else %}Show archived {{ noun }}{% endif -%} {%- endmacro %}
