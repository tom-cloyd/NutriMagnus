Beans, dried, boiled, type NS (Italy)16

{% endif %}
  • type NS — type not specified; the study didn't record which bean. A trailing small number (16) is the published table's own footnote marker, not part of the name.
  • GI 20 — always on the glucose = 100 scale, the one NuMa uses everywhere. No rescaling needed, whatever the study's reference food was. {% if gi_table and gi_table.edition == 2021 %}A ± figure is the study's standard error {{ manual_link("gloss-standard-error", "?") }}.{% endif %}
    • {% if gi_table and gi_table.edition == 2021 %}
  • tested 1992 — when the study was run, not when it was published: a commercial product measured decades ago may have been reformulated since. Hover it to see which edition and published table the row came from. A row reading 2008 edition instead was carried forward from the older table because 2021 does not appear to cover that food, and has no year on record.
  • non-ISO method — flags a 2021 row whose study deviated from the ISO 26642:2010 standard — fewer than ten subjects, an unusual carbohydrate portion, or widely scattered results. Prefer a row without it when one exists.
    • {% else %}
  • 2008 edition — every row says this, because it is the only table this install has. The 2021 edition would give the year each study was run and flag the ones with weaker method. How to add it
    • {% endif %}
  • Impaired — who the food was tested in, not a claim about the food: glucose-intolerant or diabetic subjects, whose blood glucose responds differently. With normal glucose tolerance, prefer a Normal row when one exists. {% if gi_table and gi_table.edition == 2021 %}On a 2021 row this is the study's own reported subject group, shown after it in brackets. On a 2008 row it is which of that edition's two tables the row sat in, which is all that edition recorded.{% else %}On these 2008 rows it is which of that edition's two tables the row sat in — all that edition recorded — so it also picks up some rows flagged only for very few subjects or widely scattered results. Be sceptical of extreme Impaired values.{% endif %} {{ manual_link("gi-populations", "Learn more") }}
  • ref {% if not (gi_table and gi_table.edition == 2021) %}Bread, 2h {% endif %}76 — which source study the value came from ({% if gi_table and gi_table.edition == 2021 %}76{% else %}the trailing 76{% endif %}; a UO code means unpublished observations){% if not (gi_table and gi_table.edition == 2021) %}, and the study's method: the comparison food it fed (Bread, or Glucose) and how long blood glucose was tracked (2h){% endif %}.

What NuMa saves: the number, plus a one-line record of the row you took it from — shown under the GI box here and on the food's own page, so you can always see where a value came from. Type over the number by hand and that record is dropped, since it would no longer describe the value.
