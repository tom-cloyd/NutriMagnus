Recipes cache their protein-quality score (DCP) so it doesn't need recalculating every time it's displayed. Whenever a food or recipe changes, NuMa automatically recalculates DCP for every recipe that depends on it. This list is only for the rare case where that automatic recalculation itself failed (a software error, not a data problem) — it exists so a failure like that can never just flash by and be forgotten. It does not list recipes that show "NC" (not computed) because they're missing amino acid data or have 0 servings — that's expected, not an error, and isn't logged here. {{ manual_link("system-issues-howto", "Full explanation in the manual") }}
